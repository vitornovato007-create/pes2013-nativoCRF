# Runtime nativo

Esta pasta receberá os subsistemas portáveis do runtime. Não há implementação de compatibilidade com o executável do jogo neste momento.

Proposta de módulos futuros:
- core: ciclo de vida, configuração e logging;
- platform: abstrações portáveis;
- graphics: interface de renderização e backends;
- audio: interface de áudio;
- input: interface de controles;
- compatibility: APIs identificadas na auditoria.
